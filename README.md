# 逐页故事续播台

展厅嘈杂或拥挤时，照护者可以用它提前录好“接下来会发生什么”的逐页故事：一次只显示一页，按按钮或键盘 ← / → 翻页。浏览器被误关或刷新后，会从离开的那一页继续，避免孩子因重复和顺序变化而焦虑。

当展厅**临时改道**或孩子**情绪紧张**、来不及准备故事时，编辑页旁还提供独立的**现场选择板**：照护者现场发布“一句提示 + 2–4 个选项”，孩子点选其中一项后本轮立即锁定。

## 功能

- 录入 **2–12 页**故事；每页包含**非空标题**、**非空说明**，并从**六个内置主题色**中选择一色。
- 演示前可用每页的“上移 / 下移”调整叙事次序（与相邻页交换，首项“上移”、末项“下移”自动禁用），无需删除重填；调整先同步写入快照，刷新后按数组原序恢复，旧快照无需迁移。
- 启动演示后一次只显示一页，可用界面按钮或键盘左右方向键前后移动，最后一页可标记“完成”。
- 演示默认仍为**手动模式**；照护者可通过“自动翻页”开关启停计时：开启后每 **8 秒**自动提交下一页，剩余秒数实时显示。手动按按钮或方向键前后翻页会从当前页重新计时；到达最后一页自动停止，仍需手动点击“完成”。
- 演示中可展开**页码导航**：以页码 + 标题列出启动时冻结的故事副本，选中任一页即回到单页画面，后续按钮、方向键与自动播放都从该页继续（自动模式下成功跳转从完整 8 秒重新计时）。跳转沿用“先写快照后更新”链路：写入失败时导航保持打开并标出未能跳转的页，当前页与倒计时维持原状，可重试或关闭导航。
- 创建、编辑、启动、翻页、切换播放模式、完成、重新开始，每个操作都**先同步写入 localStorage 快照，成功后才更新界面**；写入失败会给出错误提示且界面保持不变（自动翻页写入失败时会停在原页并关闭自动播放）。
- 刷新 / 误关后恢复：页码、内容、完成状态与播放模式与离开前完全一致；刷新时若处于自动播放，计时从完整 8 秒重新开始。
- “重新开始”回到第一页并**覆盖**旧进度；“回到编辑”保留草稿、结束会话。
- 编辑草稿与演示会话相互独立：启动时会冻结一份故事副本，之后改草稿不影响进行中的演示。

## 现场选择板

- 编辑页旁的**独立入口**（页面中的“打开现场选择板”，或直接访问 `#choice`），不依赖任何故事内容。
- 照护者填写**一句提示**与 **2–4 个非空、不重复的选项**后发布；发布服务只接受完整内容，缺提示、空选项、选项重复或数量越界都会被逐条标注且不会发布。
- 每轮选择由**独立标识、提示、选项、创建时间、阶段（待选择 / 已选定）与选定结果**组成；再次发布追加为新的独立轮次，表单会用上一轮内容预填，便于修改后发布下一轮。
- 孩子点选任一选项后，本轮立即**锁定**：所有选项禁用、结果高亮，不能改选；选择服务只接受**当前待选择轮次中**的选项，旧轮次或陌生选项 id 一律拒绝。
- 发布与选择都**先同步写入 localStorage，成功后才更新画面**；写入失败时保留操作前内容（表单输入或待选择状态不变），并在表单或被点击选项附近说明未保存，恢复后可直接重试。
- 刷新后恢复**最后一轮及其锁定结果**（历史轮次一并保留）。
- 选择板数据损坏时**只阻断选择板入口**，给出“清除损坏数据并重建”出口；故事草稿与演示快照的载入完全不受影响，反之亦然。

## 本地数据范围（重要）

- 所有数据**只保存在当前浏览器的 `localStorage`** 中。故事与选择板使用**两个相互独立的键**：
  - `story-resume:snapshot`：故事草稿与演示会话；
  - `choice-board:rounds`：现场选择板的历轮选择。
- 故事快照包含 `schemaVersion`（当前为 `1`）、编辑草稿与演示会话（页面副本、当前页码、完成状态、播放模式）。缺少播放模式字段的旧快照按手动模式恢复，无需迁移。
- 选择板数据包含 `schemaVersion`（当前为 `1`）与按时间排列的轮次数组；每轮的选项数量、选项唯一性、阶段与结果必须自洽。
- **不接入任何业务后端或在线服务**，不上传、不分析、不追踪；断网也能正常使用。
- 数据仅存于本机当前浏览器：换浏览器 / 换设备看不到；清除浏览器站点数据会一并删除。
- 恢复时只接受**版本正确、页面字段完整、页码在范围内**的整体快照；任何一部分损坏都整体拒绝，绝不部分套用。此时界面会给出错误提示，可一键“清除损坏数据并重新录入”，清除前不会覆盖原有内容。
- 选择板数据同样只接受**版本正确、轮次字段完整且阶段与结果自洽**的整体数据；损坏只阻断选择板入口并允许清除重建，不影响故事数据的恢复与使用。
- 校验对草稿与会话区别对待：草稿允许**未填完**的页面（空标题/空说明），刷新后可继续编辑；演示会话中的页面则必须标题、说明非空且主题色合法。
- 浏览器禁用本地存储（如某些隐私模式）时，应用仍可运行，但会明确提示“刷新后进度将丢失”。

## 技术栈

TypeScript · Vue 3 · Vite · Vitest（快照规则、可控时钟验证自动翻页、选择板轮次构造与发布/选择校验）· Playwright（刷新续播 / 自动播放 / 完成持久化 / 损坏快照 / 选择板发布选择刷新锁定 / 损坏与写入失败）

## 本地开发

```bash
npm install
npm run dev          # 开发服务器
npm run test:unit    # Vitest：快照校验与状态仓库规则
npm run test:e2e     # Playwright：刷新续播 / 完成持久化 / 损坏快照（自动先构建）
npm run build        # 类型检查 + 产出 dist/
npm run verify       # 单元测试 + 构建 + 端到端，一次跑完
```

## Docker

```bash
# 发布静态页面，默认 8080 端口，可用 WEB_PORT 覆盖
docker compose up web                 # http://localhost:8080
WEB_PORT=3000 docker compose up web   # http://localhost:3000

# 一次性验收服务：单元测试 + 构建 + Playwright 端到端，跑完即退出
docker compose run --rm verify
# 或
docker compose up verify --abort-on-container-exit --exit-code-from verify
```

`web` 服务基于 nginx 托管 `dist/` 静态文件；`verify` 服务在容器内完成全部验收（Vitest → 构建 → Playwright 对 `vite preview` 产物跑端到端），退出码即验收结果。

## 目录结构

```
src/
  lib/story.ts         # 页面模型、六个内置主题色、2-12 页规则
  lib/snapshot.ts      # 故事快照：schemaVersion、整体校验、localStorage 读写
  lib/store.ts         # 故事状态仓库：所有变更先写快照再反馈
  lib/choice.ts        # 现场选择板：轮次构造、发布校验（2-4 个非空不重复选项）、单次选择锁定
  lib/choiceStorage.ts # 选择板独立键 choice-board:rounds 的整体校验与读写
  lib/choiceStore.ts   # 选择板仓库：发布/选择先落盘再更新，损坏与写入失败独立处理
  components/          # 编辑器 / 演示器 / 损坏快照提示 / 现场选择板 / 选择板损坏提示
e2e/resume.spec.ts      # Playwright：刷新续播、完成持久化、损坏恢复
e2e/choice-board.spec.ts # Playwright：发布三选项→选择锁定→刷新确认，损坏数据与写入失败
```
